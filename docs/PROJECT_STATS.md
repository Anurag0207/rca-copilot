# RCA Copilot: project stats

Generated by `scripts/project_stats.py` on 2026-10-26. Counts are measured from the repository; evaluation figures are read from the saved evaluation JSON. All evaluation data is synthetic.

## Shareable summary

- Source-agnostic root cause analysis: 3 pluggable evidence connectors (Elasticsearch, MongoDB, Hive), queried in parallel with per-source timeouts and partial results.
- Deterministic correlation (z-score spikes, error signatures, cross-source timeline) feeds a local LLM (`qwen2.5:7b`) that must cite real evidence ids; hypotheses without valid evidence are rejected.
- Evaluated on 10 synthetic incident scenarios (2 hard) with real stores at 100k+ events each: 56% strict top-1, 72% top-3 on the first complete run; 103,948 events narrowed to about 8.3 cited records per analysis.

## What these numbers do not show

- Scenarios were written by the same people who built the system; matching is keyword-based, so it measures wording and citation, not reasoning quality.
- The fresh generalisation scenarios and the final re-evaluation have not been run yet, so there is no held-out result.
- Metrics were stored in MongoDB (Hive-shaped rows) because no Hive cluster was available.
- One machine, one local 7B model, 5 runs per scenario: per-scenario percentages move in 20-point steps.
